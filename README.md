# MY FITNESS PWA

個人用の食事・ランニング・筋トレ管理アプリ。外部サービス・アカウント不要。データは端末のブラウザのlocalStorageに保存されます。

## 起動

- フォルダで `python -m http.server 8000` を実行し、同じPCのブラウザで `http://localhost:8000` を開く。
- スマホでホーム画面に追加するには、フォルダのファイルを静的HTTPSホスティング（GitHub Pages、Cloudflare Pages等）に配置して公開URLをSafari/Chromeで開く。
- iPhone Safari: 共有 → ホーム画面に追加。
- Android Chrome: メニュー → アプリをインストール（またはホーム画面に追加）。

## 注意

- `index.html` をファイルとして直接開くとPWAインストール・オフラインキャッシュは動作しません。
- 初回読み込み後はService Workerでオフライン起動に対応します（対応ブラウザでHTTPS配信の場合）。
- ブラウザのサイトデータを削除すると記録が消えます。設定画面から定期的にJSONバックアップを保存してください。
- 栄養素や食費は推定目標・参考予算であり、食品成分表連動の自動計算ではありません。
- 朝・夜のランニングは自由記録です。両方走ることを推奨するものではありません。
